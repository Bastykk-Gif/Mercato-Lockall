Activer la sauvegarde partagée entre tous les utilisateurs (Firebase, gratuit)
  1. Aller sur console.firebase.google.com → « Ajouter un projet » → lui donner un nom (ex. repartition-sites) → Créer (l'étape Google Analytics peut être désactivée).
  2. Dans le projet : menu Build → Firestore Database → « Créer une base de données » → mode « test » → choisir une région → Activer.
  3. Aller dans Paramètres du projet (icône ⚙) → onglet « Général » → section « Vos applications » → cliquer sur l'icône Web </> → donner un nom → Enregistrer l'application. Copier l'objet firebaseConfig affiché.
  4. Dans le code de cette page, remplacer la ligne const FIREBASE_CONFIG = null; par const FIREBASE_CONFIG = { ...l'objet copié... };, puis enregistrer/committer le fichier.
  5. Dans Firestore → onglet « Règles », remplacer par : 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /repartition/{document=**} {
      allow read, write: if true;
    }
  }
}
    puis « Publier ». (Ces règles rendent les données modifiables par quiconque connaît l'URL de la page — adapté à un outil interne, pas à des données sensibles.)

Tant que cette configuration n'est pas faite, vos modifications sont sauvegardées uniquement dans ce navigateur (elles ne sont pas visibles par vos collègues).
